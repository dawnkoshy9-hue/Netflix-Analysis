Movies Data Analysis

EDA and data cleaning on a **9,827-movie dataset** using Python.

## What I Did
- Converted `Release_Date` to datetime and extracted the year
- Dropped low-value columns (`Overview`, `Original_Language`, `Poster_Url`)
- Handled outliers in `Popularity`
- Binned `Vote_Average` into rating categories
- Split and cleaned comma-separated `Genre` values

## Tech Stack
Python · Pandas · NumPy · Matplotlib · Seaborn
